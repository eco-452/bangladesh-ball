# বাংলাদেশ বল — PWA প্যাকেজ (MH Academy)

ট্রাম্পোলিনে লাফ দিলেই বাজে জাতীয় সঙ্গীতের পরের নোট। ৫টি লেভেল: বাংলাদেশ, ভারত, জাপান, যুক্তরাষ্ট্র, যুক্তরাজ্য।

## ডিপ্লয় (Vercel / GitHub Pages / যেকোনো স্ট্যাটিক হোস্ট)
1. এই ফোল্ডারের সব ফাইল হোস্টের রুটে আপলোড করুন (`index.html` রুটে থাকতে হবে)।
2. **ডোমেইন বদলান:** `index.html`, `robots.txt`, `sitemap.xml`-এ `https://bangladesh-ball.vercel.app` লেখা আছে। এটা আপনার আসল ডোমেইন দিয়ে Find & Replace করুন।
3. GitHub Pages সাবফোল্ডারে (`/repo-name/`) হোস্ট করলে `manifest.webmanifest`-এ `start_url` ও `scope` বদলে `./` করুন।
4. `sw.js` বদলালে ভিতরের `VERSION` সংখ্যা বাড়ান, তাহলে পুরনো ক্যাশ মুছে যাবে।

## ফোল্ডার
- `index.html` — পুরো গেম (HTML + CSS + JS এক ফাইলে), SEO মেটা ট্যাগ ও JSON-LD সহ
- `manifest.webmanifest`, `sw.js` — PWA ও অফলাইন সাপোর্ট
- `icons/` — ১৬ থেকে ১০২৪ px PNG, maskable ১৯২/৫১২, apple-touch-icon, SVG, Safari pinned-tab, Windows tile
- `favicon.ico`, `browserconfig.xml`
- `banner/` — og-banner (১২০০×৬৩০), cover (১৫০০×৫০০), square (১০৮০×১০৮০), story (১০৮০×১৯২০)
- `screenshots/` — ইনস্টল প্রম্পটের স্ক্রিনশট
- `fonts/` — Hind Siliguri (সেলফ-হোস্টেড, অফলাইনে চলে)
- `robots.txt`, `sitemap.xml`, `vercel.json` (ক্যাশ ও সিকিউরিটি হেডার)

## সুর বদলাতে চাইলে
`index.html`-এ `LV` অ্যারের প্রতিটি লেভেলের `mel` ফিল্ডে নোটের নাম লেখা আছে (যেমন `G4 A4 F#4`)। সেখানে নোট বদলালেই সুর বদলে যাবে।

## সুরের সূত্র
- লেভেল ১ (বাংলাদেশ): আপনার ভিডিওর অডিও থেকে প্রতিটি লাফের নোট আলাদা করে বের করা। অটোমেটিক বিশ্লেষণ, তাই দু-একটা নোটে ভুল থাকতে পারে।
- অন্য লেভেল: ভারত, জাপান, যুক্তরাজ্য ও যুক্তরাষ্ট্রের (প্রথম অংশ) সুর পাবলিক-ডোমেইন স্কোর/নোট থেকে নেওয়া।
